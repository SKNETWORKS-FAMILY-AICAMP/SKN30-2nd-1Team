1️⃣ 환경 준비
# Python 3.9+ 와 uv 가 설치되어 있어야 합니다 $ python --version # >= 3.9 $ uv --version # 의존성 설치 (lock 파일 기준) $ uv sync
2️⃣ Streamlit 앱 실행
# 프로젝트 루트에서 실행 $ uv run streamlit run app/main.py # 브라우저: http://localhost:8501
3️⃣ 발표 슬라이드 보기
# 정적 서버로 띄우면 슬라이드 fetch가 동작 $ python -m http.server 8000 \ --directory reports/presentation # 브라우저: http://localhost:8000
