요구사항 정의서

🛠 기능 요구사항
· 채널 URL/ID 입력 검색
· 위험도 점수 + A/B/C 등급 출력
· 6가지 위험 신호 시각화
· SHAP 위험 원인 TOP 3 표시
· 장기/단기/카테고리 추천
· 댓글 감성 분석 (KoBERT)
· 대시보드 전체 현황 (KPI)
⚡ 비기능 요구사항 (KPI)
이탈 Recall≥ 80%
이탈 F1 Score≥ 0.7
ROC-AUC≥ 0.85
채널당 처리 시간≤ 5초
대시보드 사용성정성 평가
📂 데이터 요구사항
· 한국 YouTube 채널 (구독자 10만+)
· YouTube Data API v3 활용
· 채널당 영상 50개 수집
· 스냅샷 기반 (2026-05-17)
· 학습 데이터에만 SMOTE 적용
· 비공개 데이터 사용 금지
· CSV 기반 저장 (MVP)
왜 Recall 우선? 광고주 관점에서 이탈 채널을 놓치는 비용(FN)이 잘못된 위험 경고(FP)보다 훨씬 크기 때문에, F1·Accuracy 대신 Recall을 최우선 평가 지표로 설정.
