# dataset_wide.csv — 피처 설계 문서

## 피처 구성 원칙

이탈 예측에서 "이탈"이란 **크리에이터가 유튜브 활동을 중단하거나 급격히 줄이는 현상**입니다.  
이를 예측하려면 단순히 구독자 수 같은 정적인 수치가 아니라  
**행동 패턴의 변화**를 잡아야 합니다.

피처는 이 질문들에 답하는 방향으로 설계되었습니다.

> "이 크리에이터가 **얼마나 자주**, **얼마나 규칙적으로** 올리고 있는가?"  
> "최근에 **반응이 줄어들고** 있는가?"  
> "**공백이 길어지고** 있는가?"  
> "**Shorts로 전환**하고 있는가?"

---

## 피처 그룹별 설명

### 그룹 0 — 채널 기본 정보 (원시값)
channels 테이블에서 직접 가져온 값입니다.  
모델에 직접 쓰이기보다 다른 피처 계산의 기반이 됩니다.

| 피처 | 의미 | 이탈과의 관계 |
|---|---|---|
| `channel_id` | 채널 고유 ID | 조인 키 — 모델 미사용 |
| `title` | 채널명 | 텍스트 — 모델 미사용 |
| `published_at` | 채널 개설일시 | → `channel_age_days`로 변환해서 사용 |
| `country` | 채널 국가 코드 | null 존재, 현재 샘플에서 범주 적어 모델 미사용 |
| `subscriber_count` | 구독자 수 | 구독자가 많을수록 이탈 부담이 커 활동 유지 경향 |
| `view_count` | 채널 누적 조회수 | 높을수록 수익 기반 확보 → 활동 지속 가능성 높음 |
| `total_video_count` | 채널 전체 영상 수 (API 기준) | 오래 활동한 채널일수록 큼 |
| `source_file` | 수집 파일명 | 추적용 — 모델 미사용 |

---

### 그룹 A — 활동성 피처
"**얼마나 자주, 얼마나 규칙적으로 올리는가**"를 수치화합니다.  
이탈 예측에서 가장 직접적인 신호를 담고 있습니다.

| 피처 | 계산 방법 | 의미 | 이탈 신호 |
|---|---|---|---|
| `collected_video_count` | 수집된 영상 수 (최대 50) | API 수집 한도 내 영상 수 | 너무 적으면 최근 활동 없음을 간접 시사 |
| `days_since_last_upload` | 오늘 − 가장 최근 업로드일 | 마지막 업로드 후 경과 일수 | **이탈 라벨 생성 기준 컬럼** (90일 이상 = 이탈). 모델 학습에선 제외 |
| `avg_upload_interval_days` | 업로드 날짜 간격의 평균 | 평균 업로드 주기 (일) | 높을수록 드문드문 올림 |
| `std_upload_interval_days` | 업로드 간격의 표준편차 | 업로드 규칙성 | 높을수록 불규칙 — 활동 불안정 신호 |
| `max_gap_days` | 업로드 간격 중 최댓값 | 역대 가장 긴 공백 기간 | 극단적으로 크면 한 번 쉰 전적이 있는 채널 |
| `hiatus_count_30d` | 30일 이상 간격 횟수 | 장기 공백이 몇 번 있었는지 | 반복적 공백은 이탈 패턴의 선행 지표 |
| `upload_freq_change_rate` | (최근 3개월 − 이전 3개월) / 이전 3개월 | 업로드 빈도 변화율 | 음수면 최근에 업로드가 줄어드는 중. **이전 3개월이 0이면 분모 0 → clip(-5, 5) 처리 필요** |

---

### 그룹 B — 성과 피처
"**영상이 얼마나 반응을 얻고 있는가, 최근에 반응이 줄었는가**"를 측정합니다.  
수익과 직결되어 이탈 결정에 간접적으로 영향을 줍니다.

| 피처 | 계산 방법 | 의미 | 이탈 신호 |
|---|---|---|---|
| `avg_view_count` | 수집된 영상들의 조회수 평균 | 영상 1개당 평균 조회수 | 낮을수록 수익 기반이 약함 |
| `std_view_count` | 조회수 표준편차 | 조회수 편차 | 크면 히트작 의존형 채널 — 편차가 클수록 수익 불안정 |
| `avg_like_count` | 좋아요 수 평균 | 영상 1개당 평균 좋아요 | 낮을수록 시청자와 유대가 약함 |
| `avg_comment_count` | 댓글 수 평균 | 영상 1개당 평균 댓글 수 | 댓글이 많을수록 커뮤니티 형성 → 이탈 억제 |
| `avg_engagement_rate` | (좋아요 + 댓글) / 조회수 평균 | 시청자 참여율 | 낮아지면 채널 영향력 하락 신호 |

> **주의**: `avg_engagement_rate` 최댓값이 `6e+07`처럼 이상하게 큰 경우가 있습니다.  
> 조회수가 극단적으로 낮은 영상에서 분모가 0에 가까워지는 문제입니다.  
> 모델 학습 전 `clip(0, 1)` 또는 이상값 제거를 권장합니다.

---

### 그룹 C — Shorts 피처
"**Shorts로 전환하고 있는가, Shorts 성과가 어떤가**"를 측정합니다.  
Shorts는 일반 영상과 알고리즘·수익 구조가 달라 채널 전략 변화의 지표가 됩니다.

| 피처 | 계산 방법 | 의미 | 이탈 신호 |
|---|---|---|---|
| `shorts_ratio` | Shorts 영상 수 / 전체 영상 수 | Shorts 비율 | 갑자기 급증하면 일반 영상 포기 신호일 수 있음 |
| `avg_shorts_view` | Shorts 영상 조회수 평균 | Shorts 1개당 평균 조회수 | Shorts 없는 채널은 0으로 채움 |
| `avg_normal_view` | 일반 영상 조회수 평균 | 일반 영상 1개당 평균 조회수 | Shorts만 있는 채널은 null → 0 처리 |

> **Shorts 판별 기준**: `is_shorts == True` 컬럼 사용.  
> API에서 직접 Shorts 구분을 제공하지 않으므로 이 값은 수집 단계에서 60초 이하 + 세로형 조건으로 파생된 값입니다.

## 피처 간 관계 요약

```
채널 기본 정보        활동성             성과              Shorts
─────────────────   ──────────────────  ───────────────   ──────────────────
subscriber_count    avg_upload_interval  avg_view_count    shorts_ratio
view_count          std_upload_interval  std_view_count    avg_shorts_view
total_video_count   max_gap_days         avg_like_count    avg_normal_view
channel_age_days*   hiatus_count_30d     avg_comment_count
                    upload_freq_change   avg_engagement
                    collected_video_count
```
`*` published_at에서 파생, 전처리 단계에서 생성

---

## 모델 학습 시 제외 피처 및 이유

| 피처 | 제외 이유 |
|---|---|
| `days_since_last_upload` | **데이터 리크**: 이탈 라벨(is_churned) 생성에 직접 사용한 컬럼 |
| `channel_id`, `title`, `source_file` | ID / 텍스트, 모델에 의미 없음 |
| `published_at` | 날짜 문자열 → `channel_age_days`로 변환 후 사용 |
| `country` | null 존재 + 현재 샘플 50개에서 범주가 너무 적음 |

---

## 이상값 처리가 필요한 피처

| 피처 | 문제 | 권장 처리 |
|---|---|---|
| `upload_freq_change_rate` | 이전 3개월 업로드 0인 채널 → 최대 `5e+10` | `clip(-5, 5)` |
| `avg_engagement_rate` | 조회수 극소인 영상에서 분모 0 → 최대 `6e+07` | `clip(0, 1)` |
