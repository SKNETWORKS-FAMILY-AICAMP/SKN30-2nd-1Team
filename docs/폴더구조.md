# 폴더 구조

skn-proj2 (유튜버 이탈 예측 AI) 프로젝트의 전체 디렉토리 구조 정리.

## 전체 트리

```
skn-proj2/
├── app/                       # Streamlit 데모 앱
├── configs/                   # 설정 파일
│   └── config.yaml
├── data/                      # 데이터 (git 추적 — 팀 공유)
│   ├── raw/                   # 원시 데이터 (수정 금지)
│   │   ├── youtube_channels.csv  # youtube-rank 크롤링 마스터 (channel_id + is_churned 라벨)
│   │   ├── channels/          # 채널별 상세 (YouTube Data API v3)
│   │   │   ├── csv/
│   │   │   └── json/
│   │   └── videos/            # 영상별 상세 (YouTube Data API v3)
│   │       ├── csv/
│   │       └── json/
│   └── processed/             # 전처리·피처 엔지니어링 결과
│       ├── features/
│       └── splits/            # train / val / test
├── docs/                      # 문서·산출물
│   ├── README.md
│   ├── 플랜1.md
│   ├── 폴더구조.md            # (이 문서)
│   └── superpowers/           # 작업 플랜 보관
│       └── plans/
├── notebooks/                 # Jupyter 탐색·실험 노트북
│   └── 01_data_collection/
│       ├── 01a_channel_info.ipynb
│       └── 01b_video_info.ipynb
├── src/                       # 프로덕션 소스코드
│   ├── data/                  # 수집 (scraper, youtube_api, loader)
│   ├── preprocessing/         # 전처리 (cleaner, encoder, splitter)
│   ├── features/              # 피처 엔지니어링 (A~E 카테고리)
│   ├── models/                # 모델
│   │   ├── ml/                # LR, RF, XGBoost, LightGBM
│   │   └── dl/                # KoBERT 감성, 분류 모델
│   ├── evaluation/            # metrics, visualizer, SHAP
│   └── utils/                 # config, logger
├── saved_models/              # 학습된 모델 아티팩트 (.gitignore)
├── reports/                   # 자동 생성 그래프·리포트
├── .env / .env.example        # API 키 등 환경변수
├── CLAUDE.md                  # 프로젝트 가이드
├── README.md
├── main.py
├── pyproject.toml             # uv 의존성
└── uv.lock
```

## 폴더별 역할 요약

| 폴더 | 역할 | 주요 산출물 | gitignore |
|---|---|---|---|
| `app/` | Streamlit 데모 앱 | `main.py`, `pages/`, `components/` | — |
| `configs/` | YAML 설정 | `config.yaml` | — |
| `data/raw/` | 원시 수집 데이터 | `youtube_channels.csv` (마스터), `channels/`, `videos/` | — |
| `data/processed/` | 전처리·피처 결과 | `features_YYYYMMDD.csv`, `train/val/test.csv` | — |
| `docs/` | 문서·제출 산출물 | 전처리 결과서, 학습 결과서, 발표자료 | — |
| `notebooks/` | 실험용 Jupyter | 번호별 `.ipynb` | — |
| `src/` | 프로덕션 모듈 | 패키지화된 `.py` | — |
| `saved_models/` | 학습 모델 아티팩트 | `{모델}_{날짜}_{AUC}.pkl` | ✅ |
| `reports/` | 평가 그래프·표 | `*_roc_curve.png`, `shap_summary.png` | — |

## 데이터 흐름과 폴더 매핑

```
[수집]    youtube-rank.com  ──► data/raw/youtube_channels.csv  (마스터: channel_id + 라벨)
          YouTube API v3    ──► data/raw/channels/  (채널별 상세)
                            ──► data/raw/videos/    (영상별 상세)
                                      │
[전처리]                              ▼
          src/preprocessing/  ──► data/processed/splits/
          src/features/       ──► data/processed/features/
                                      │
[학습]                                ▼
          src/models/         ──► saved_models/
                                      │
[평가]                                ▼
          src/evaluation/     ──► reports/
```

## 작업 규칙

- `data/raw/` 는 수집 후 절대 수정하지 않는다. 모든 가공 결과는 `data/processed/` 에 저장.
- `notebooks/` 에서 검증된 코드는 반드시 `src/` 로 모듈화하여 재사용한다.
- `data/` 는 git 으로 팀과 공유한다 (5명이 quota 분할 수집 → push/pull 로 통합).
- 학습된 모델(`saved_models/`)은 바이너리·용량 문제로 git 제외, 별도 드라이브 사용.
- 파일명에 날짜(`YYYYMMDD`)와 평가 지표를 포함해 버전을 구분한다.
