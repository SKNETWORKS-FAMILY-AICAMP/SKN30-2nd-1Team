# 2. 시장 배경 (Market Context)

## 2-1. 국내 크리에이터 / 인플루언서 마케팅 시장 성장

- **국내 디지털 크리에이터 산업 매출**: 2025년 기준 약 **5조 5천억 원** 규모
- 국내 인플루언서 마케팅 시장은 매년 두 자릿수 성장률을 기록 중이며, 광고주의 디지털 광고비 중 크리에이터 채널 비중이 지속 확대되고 있다
- 국내 MCN 산업 역시 확장되며 **장기 계약 기반 협업**이 보편화되는 추세이다

### (참고) 글로벌 시장 동향
국내 시장은 글로벌 시장과 유사한 성장 곡선을 그리고 있다.
- 글로벌 인플루언서 마케팅 시장: 2025년 약 330억 달러 규모
- 미국 크리에이터 광고 지출: 2025년 약 370억 달러, 전체 미디어 광고 시장 대비 약 4배 빠른 성장세

→ 글로벌 트렌드가 국내에도 빠르게 확산되는 만큼, 국내 시장에서도 **데이터 기반 크리에이터 평가** 수요가 커지고 있다.

## 2-2. 국내 시장 트렌드 변화

국내 광고주/에이전시의 채널 평가 기준이 변화하고 있다:

| 기존 | 최근 |
|---|---|
| 단순 유명 인플루언서 | 지속 활동 + 팬덤 충성도 높은 채널 |
| 단발성 캠페인 | 장기 파트너십 |
| 감(感) 기반 선정 | 데이터 기반 ROI 중심 |

특히 국내 광고주들은 최근 **장기 협업 가능성**과 **활동 지속 가능성**을 핵심 평가 기준으로 보고 있다.

## 2-3. 국내 시장 공백 (Market Gap) 및 차별점

국내에서 활용 가능한 기존 분석 서비스(Playboard, NoxInfluencer 한국 채널 등)는 대부분 **현재 인기 지표** 중심이며,
**한국어 댓글 감성**이나 **국내 채널의 활동 지속 가능성**을 정량적으로 예측하는 도구는 부족하다.

본 프로젝트는 **국내 채널 + 한국어 댓글** 환경에 특화하여 **미래 활동 지속 가능성**을 예측하고
**SHAP 기반 설명 가능성**을 제공한다는 점에서 차별화된다.

| 구분 | 기존 서비스 | 튜브어때 |
|---|---|---|
| 분석 대상 | 글로벌 일반 채널 | **국내 YouTube 채널 특화** |
| 댓글 분석 | 미지원 또는 영어 위주 | **한국어 KoBERT 감성 분석** |
| 분석 시점 | 현재 인기 | 미래 지속 가능성 |
| 핵심 지표 | 구독자/조회수 | 이탈 위험도 + 감성 변화 |
| 결과 해석 | 단순 랭킹 | SHAP 기반 위험 원인 설명 |

# 3. 문제 정의 (Problem Statement)

최근 인플루언서 마케팅 시장은 빠르게 성장하고 있으며, 브랜드들은 유튜버와 장기 광고 계약을 체결하고 있다.

하지만 현재 광고주들은 대부분:

- 구독자 수
- 평균 조회수
- 최근 인기 영상
- 채널 인지도

등 단순 지표를 기반으로 크리에이터를 선정하고 있다.

문제는 이러한 지표가 "현재 인기"만 보여줄 뿐, 채널의 장기 활동 지속 가능성이나 안정성을 설명하지 못한다는 점이다.

예를 들어:

- 업로드 주기가 점점 길어지는 채널
- 조회수가 지속 감소하는 채널
- 댓글 반응이 부정적으로 변화하는 채널

은 향후 활동 중단 또는 채널 영향력 하락 가능성이 존재할 수 있다.

그러나 현재 시장에는 이를 사전에 정량적으로 분석해 광고주에게 제공하는 시스템이 부족하다.

본 프로젝트의 목표는 YouTube 데이터를 활용하여:

- 크리에이터의 활동 지속 가능성 분석

기능을 제공하는 것이다.

이를 통해 광고주는 보다 안정적인 크리에이터와 계약할 수 있으며, 광고 리스크를 줄일 수 있다.

# 6. 핵심 기능 (Core Features)

## 6-1. 채널 위험도 예측

### 설명
사용자가 입력한 YouTube 채널을 **사전 수집된 스냅샷 데이터** 기반으로 분석하여
해당 채널의 이탈 위험도를 예측한다.

### 사용자 입력
- YouTube **채널 URL** 또는 **채널 ID**
  - 예: `https://www.youtube.com/@channelname` / `UCxxxxxxxxxxxxxxxxxx`

### 분석 데이터 출처 (MVP 기준)
- **2026-05-17 기준 크롤링 스냅샷 데이터** 사용
- 사용자가 입력한 채널 ID/URL을 키로 사전 수집된 **CSV 파일**(`data/processed/*.csv`)에서 채널 정보 조회
- CSV에 없는 채널의 경우: 분석 불가 메시지 출력 (향후 실시간 수집으로 보완 예정)

> ※ MVP에서는 **실시간 YouTube API 호출 없음** — 사전 수집 데이터로만 분석.
> 이유: YouTube API 일일 쿼터 제한 + 분석 처리 시간 5초 이내 KPI 충족.

### 모델 내부 Feature (자세한 정의는 10장 참조)
- 업로드 패턴 (업로드 주기, 마지막 업로드 경과일 등)
- 조회수 / 성장 지표 (조회수 변화율, 변동성 등)
- 참여율 (좋아요/조회수, 댓글/조회수 등)
- 댓글 감성 점수 (KoBERT 기반)

### 출력 결과
- 위험도 점수 (%)
- 등급 (A/B/C)
- 주요 위험 원인 (SHAP 기반 Top-3)
- **데이터 기준일 안내** (예: "2026-05-17 기준 데이터로 분석되었습니다")

# 9. 데이터 수집 계획

## 9-1. 데이터 소스

| 데이터 | 출처 (YouTube Data API v3) | 설명 |
|---|---|---|
| 채널 정보 | `channels` endpoint | 구독자 수, 총 조회수, 채널 생성일 |
| 영상 정보 | `videos` / `search` endpoint | 업로드 날짜, 조회수, 좋아요, 댓글 수 |
| 댓글 데이터 | `commentThreads` endpoint | 댓글 내용, 작성일, 좋아요 수 |
| 참여 데이터 | 위 데이터 가공 | 좋아요/조회수 비율, 댓글/조회수 비율 |

## 9-2. 수집 규모 (목표)

| 항목 | 규모 |
|---|---|
| 대상 채널 수 | 약 2,000개 (한국 채널, 구독자 1만 이상) |
| 채널당 영상 수 | 최근 100개 영상 |
| 영상당 댓글 수 | 상위 50개 (좋아요 순) |
| 수집 기간 | 과거 24개월 |

## 9-3. API 쿼터 관리

- YouTube Data API 일일 쿼터: 키당 10,000 units
- **다중 API 키 로테이션**으로 쿼터 확장
- 수집 결과 **로컬 캐시** (`data/raw/`)로 재호출 최소화
- 실패 채널은 `failed_channels_*.csv`로 별도 관리 후 재시도

## 9-4. 수집 주기

- MVP 단계: **1회성 배치 수집**
- 확장 단계: 주 1회 정기 배치로 시계열 데이터 누적

# 10. Feature Engineering

## 10-1. 업로드 패턴 Feature

| Feature | 정의 |
|---|---|
| `upload_interval_30d` | 최근 30일 평균 업로드 간격 (일) |
| `upload_interval_90d` | 최근 90일 평균 업로드 간격 (일) |
| `upload_interval_trend` | (최근 30일 간격 − 최근 180일 간격) / 최근 180일 간격 |
| `days_since_last_upload` | 마지막 업로드 이후 경과 일수 |

## 10-2. 조회수 / 성장 Feature

| Feature | 정의 |
|---|---|
| `view_growth_rate` | 최근 5개 영상 평균 조회수 / 직전 5개 영상 평균 조회수 |
| `view_volatility` | 최근 20개 영상 조회수 표준편차 / 평균 |
| `subscriber_to_view_ratio` | 평균 조회수 / 구독자 수 |

## 10-3. 참여율 Feature

| Feature | 정의 |
|---|---|
| `engagement_rate` | (좋아요 + 댓글) / 조회수 |
| `like_view_ratio` | 좋아요 / 조회수 |
| `comment_view_ratio` | 댓글 수 / 조회수 |
| `engagement_trend` | 최근 5개 영상 참여율 − 직전 5개 영상 참여율 |

## 10-4. 댓글 감성 Feature

| Feature | 정의 |
|---|---|
| `sentiment_positive_ratio` | 긍정 댓글 비율 |
| `sentiment_negative_ratio` | 부정 댓글 비율 |
| `sentiment_trend` | 최근 댓글 감성 점수 − 과거 댓글 감성 점수 |

# 12. 모델 정의

## 12-1. 이탈(Target) 정의

```text
90일 이상 신규 영상 업로드가 없는 채널 = 이탈(1)
정상적으로 활동 중인 채널 = 활동(0)
```

### 90일 기준 근거
- YouTube 크리에이터 평균 업로드 주기 분석 결과, 활동 채널의 95% 이상이 90일 이내 신규 업로드
- 60일은 휴재/시즌제 채널이 과대 분류될 위험
- 180일은 이미 채널이 사실상 종료된 상태일 가능성 높음

### 예외 처리
- **시즌제 채널** (예: 연 1~2회 시리즈 업로드): 별도 라벨링 검토
- **단기 휴재 후 복귀** 채널: 라벨 재계산

## 12-2. 사용 모델

### ML
- Logistic Regression (baseline)
- RandomForest
- XGBoost
- LightGBM

### DL
- KoBERT 기반 댓글 감성 분석

## 12-3. 평가 지표

이탈 채널은 **소수 클래스(Minority Class)** 일 가능성이 높으므로 단순 Accuracy로 평가할 수 없다.

| 지표 | 목적 |
|---|---|
| **Recall (재현율)** | 실제 이탈 채널을 놓치지 않는 능력 — **최우선 지표** |
| Precision | 이탈 예측의 정확도 |
| F1 Score | Precision과 Recall의 조화 평균 |
| ROC-AUC | 전체 분류 성능 |
| PR-AUC | 불균형 데이터에서의 분류 성능 |

> 광고주 관점에서는 **이탈 채널을 놓치는 비용(FN)** 이 **잘못된 위험 경고(FP)** 보다 크다.
> 따라서 **Recall** 을 가장 중요한 지표로 설정한다.

## 12-4. 클래스 불균형 처리

예상 이탈 비율: 약 10~20%

| 전략 | 적용 방안 |
|---|---|
| `class_weight='balanced'` | 모델 단에서 손실 가중치 조정 |
| SMOTE | 학습 데이터 오버샘플링 (테스트 데이터엔 미적용) |
| Threshold Tuning | 기본 0.5 임계값을 Recall 기준으로 조정 |

# 19. 한계점

- **스냅샷 기반 분석**: MVP는 2026-05-17 시점 크롤링 데이터로만 분석하므로, 이후 채널 활동 변화는 즉시 반영되지 않음
- **신규 채널 분석 한계**: 사전 수집 DB에 없는 채널은 분석 불가 (실시간 수집 미지원)
- YouTube API의 데이터 제한 존재 (일일 쿼터, 비공개 댓글 등)
- 실제 광고 계약 데이터 부재 (광고 성과와의 직접 검증 불가)
- 외부 이슈(논란, 건강 등) 반영 어려움
- 추천 결과가 광고 성과를 보장하지 않음
- 한국어 댓글 기준으로 학습되어 다국어 채널 분석 한계

# 20. 윤리적 고려사항

- 본 시스템은 **YouTube 공개 API 데이터**만 사용하며, 비공개 정보는 수집하지 않는다
- "위험 채널" 분류 결과는 **광고 의사결정 참고용**이며, 크리에이터에 대한 평가/제재 목적이 아니다
- 모델의 예측 결과는 통계적 추정치이므로, 광고주의 최종 판단을 대체하지 않는다
- 크리에이터 개인을 식별 가능한 형태로 결과를 외부 공유하지 않는다

# 21. 향후 확장 방향

- **주기적 자동 업데이트**: 현재 1회성 스냅샷 → 6시간 / 12시간 / 일 단위 정기 크롤링으로 전환
- **실시간 채널 분석**: 사용자가 입력한 신규 채널을 즉시 YouTube API로 수집·분석
- **시계열 위험도 추적**: 같은 채널의 위험도 변화를 시간 축으로 시각화
- TikTok / Instagram 확장
- 광고 성과 데이터 연동
- 자동 광고 매칭 시스템 구축
- 뉴스/SNS 외부 데이터 연동 (논란 탐지)

# 24. 용어 정의 (Glossary)

| 용어 | 정의 |
|---|---|
| 이탈 (Churn) | 90일 이상 신규 영상 업로드가 없는 상태 |
| 참여율 (Engagement Rate) | (좋아요 + 댓글) / 조회수 |
| SHAP | 모델 예측에 각 feature가 기여한 정도를 정량화하는 설명 가능성 기법 |
| MCN | Multi-Channel Network. 크리에이터 매니지먼트 기업 |
| ROI | Return on Investment. 광고 투자 대비 수익률 |
