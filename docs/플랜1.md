## 1. 데이터 전략

### youtube-rank.com CSV만으로는 핵심 피처 생성 불가 → YouTube API 추가 필수

**CSV에서 얻는 것** (채널 단위 집계값 + 이탈 레이블)
```
channel_name, category, subscriber_count, total_views, video_count,
created_date, last_updated, days_since_update, is_churned, channel_id
```

CSV만으로 만들 수 있는 피처: 채널 나이, 총 영상 수, 구독자 수, 평균 조회수 정도
→ 이탈 예측의 핵심인 **업로드 패턴 변화, 참여율, 최근 활동 추이**는 만들 수 없음

**YouTube API 호출로 추가 수집해야 하는 것**

| 엔드포인트 | 수집 데이터 | 생성 피처 |
|---|---|---|
| `playlistItems.list` | 최근 50개 영상 ID + 업로드 날짜 | 업로드 간격 통계, 최근 vs 이전 빈도 변화율, 최대 공백 기간 |
| `videos.list` | 영상별 views/likes/comments/duration | 참여율, 조회수 추세, 영상 길이 통계, Shorts 비율 |
| `commentThreads.list` | 최근 댓글 텍스트 | KoBERT 감성 점수 (DL팀, 선택적 수집) |

**수집 파이프라인 흐름**
```
[1] youtube-rank.com 크롤링
    → 채널 목록 + is_churned 레이블 + channel_id 확보
    → data/raw/channels/

[2] YouTube API 호출 (channel_id 사용)
    → playlistItems.list → 영상 업로드 타임스탬프 목록
    → videos.list → 영상별 상세 지표
    → data/raw/videos/

[3] 피처 엔지니어링
    → data/processed/features/

[4] train/val/test 분리
    → data/processed/splits/
```

## 2. API Quota 전략

### 채널 1개당 API 소모량

| 엔드포인트 | 호출 방식 | 채널당 비용 |
|---|---|---|
| `channels.list` | 50개씩 배치 | ~0.02 units |
| `playlistItems.list` | 채널당 1회 (최근 50개 영상) | 1 unit |
| `videos.list` | 채널당 1회 (50개 배치) | 1 unit |
| **소계 (댓글 없음)** | | **~2.02 units/채널** |
| `commentThreads.list` | 채널당 2~3회 | +2~3 units |
| **소계 (댓글 포함)** | | **~4~5 units/채널** |

### 10,000채널 기준 필요 units

| 수집 범위 | 필요 units |
|---|---|
| ML용 — 댓글 없음 10,000채널 | ~20,200 units |
| DL용 — 댓글 포함 10,000채널 전부 | ~45,000 units |
| ML 전체 + DL 댓글 샘플 (~3,900채널) | ~30,000 units |

---

### 시나리오 A — 계정 1개 × 3일 (금토일)

- 가용량: 10,000 units/일 × 3일 = **30,000 units**
- ML 데이터(댓글 없음) 10,000채널: ~20,200 units → 충분
- DL 댓글은 이탈/활동 채널 각 ~2,000개 샘플만 수집 → ~9,750 units

**수집 순서:**
```
Day 1 (금): channels.list + playlistItems.list 10,000채널 → ~10,100 units
Day 2 (토): videos.list 10,000채널               → ~10,000 units
Day 3 (일): commentThreads.list 샘플 ~3,900채널  → ~9,750 units
```

---

### 시나리오 B — 5명 × 4계정 = 20계정 × 1일

- 가용량: 10,000 units × 20 = **200,000 units/일**
- ML + DL 댓글 전체 10,000채널: ~45,000 units → **하루 완료, 여유 155,000 units**
- `youtube_api.py`에 Round-Robin 키 교체 로직 구현 → 자동 분산
- 각자 Google Cloud Console에서 프로젝트 4개 생성 + API 키 발급 (1인당 15분)

---

**선택 기준:**
- 시간 여유 있으면 → **시나리오 A** (계정 1개, 추가 세팅 없음)
- 빠르게 전부 수집하고 싶으면 → **시나리오 B** (20계정, 하루 완료)

**공통 체크리스트:**
- 수집 전 youtube-rank.com 실제 채널 수 확인 (10,000개 이상인지)
- 시나리오 A: Google Cloud 프로젝트 1개 + API 키 1개면 충분
