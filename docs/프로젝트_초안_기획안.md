# 사라지는 유튜버, 남겨진 광고비
**YouTube 채널 데이터 기반 크리에이터 이탈 위험도 예측 AI 모델**

---

## 📋 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **주제** | 유튜브 크리에이터 활동 중단(이탈) 위험도 사전 예측 |
| **비즈니스 관점** | 광고주가 안전한 인플루언서 파트너를 계약 전에 선별 |
| **핵심 개념** | 가입 = 광고 계약 체결 / 이탈 = 크리에이터 활동 중단 |
| **모델** | ML 4종 + DL (BERT 감성 분석) |
| **데이터** | https://youtube-rank.com 크롤링 & YouTube Data API v3 |

## 🎬 SCENE 1: 시장 배경
### "인플루언서 마케팅은 이미 거대한 산업"

> *"브랜드들이 유튜버에게 광고를 맡기는 시대가 왔습니다."*

### 핵심 데이터

- 글로벌 인플루언서 마케팅 시장 규모는 **2024년 말까지 약 240억 달러(약 35조 원)**에 이를 것으로 예상
  - 출처: [Shopify, 2025](https://www.shopify.com/kr/blog/influencer-marketing-statistics)
- 국내 인플루언서 커머스 시장 규모는 **2022년 6조 원 → 2025년 28조 원**으로 약 5배 성장 전망
  - 출처: [나스미디어, brunch.co.kr](https://brunch.co.kr/@khanhee/32)
- 2023년 **마케터의 50%**가 인플루언서와 협력, 그 중 **57.6%**가 이커머스 스토어 운영
  - 출처: [HubSpot, Shopify](https://www.shopify.com/kr/blog/influencer-marketing-statistics)

### 슬라이드 포인트
삼성·LG·올리브영 등 대기업이 유튜버와 **6개월~1년 단위 광고 계약** 체결이 일반화됨

## 🎬 SCENE 2: 문제 발견
### "그런데 계약 도중 유튜버가 사라진다면?"

> *"하지만 아무도 이 리스크를 정량화하지 않고 있습니다."*

### 핵심 데이터

- 광고 시장 하강 국면은 **인플루언서의 활동 중단 요인**으로 작용할 수 있음
  - 출처: [brunch.co.kr](https://brunch.co.kr/@khanhee/32)
- **광고주가 인플루언서의 퍼포먼스를 정확하게 추정하지 못한다는 점**이 인플루언서 마케팅의 가장 큰 단점
  - 출처: [openads.co.kr](https://openads.co.kr/content/contentDetail?contsId=11535)
- 실제 사례: 뒷광고 논란으로 **크리에이터가 활동을 잠정 중단**하는 사례 발생 → 광고주에게 직접적 손실
  - 출처: [나무위키 - 2020년 유튜버 뒷광고 사건](https://namu.wiki/w/2020%EB%85%84%20%EC%9C%A0%ED%8A%9C%EB%B2%84%20%EB%92%B7%EA%B4%91%EA%B3%A0%20%EC%82%AC%EA%B1%B4)

### 핵심 질문
> **"광고 계약 전, 이 유튜버가 계약 기간 동안 활동을 유지할지 알 수 있을까?"**

## 🎬 SCENE 3: 기존 방식의 한계
### "지금은 눈으로만 판단한다"

> *"현재 광고주는 구독자 수·조회수 같은 현재 지표만 보고 계약합니다. 미래를 보는 도구가 없습니다."*

### 기존 계약 판단 기준의 문제점

| 현재 기준 | 한계 |
|-----------|------|
| 구독자 수 | 지금 많아도 내일 그만둘 수 있음 |
| 평균 조회수 | 최근 추이가 하락 중인지 모름 |
| 콘텐츠 퀄리티 | 번아웃 신호 포착 불가 |
| 계약서 위약금 | 이탈 후 사후 대응일 뿐 |

### 핵심 메시지
> **"은행이 대출 전에 신용점수를 확인하듯, 광고주도 계약 전에 크리에이터의 '활동 지속 가능성'을 확인해야 합니다."**

---

## 🎬 SCENE 4: 해결책 제시
### "크리에이터 신용등급 모델"

> *"YouTube API 데이터를 분석하면 이탈 신호가 보입니다."*

### YouTube API로 포착 가능한 이탈 신호

| 신호 | 의미 |
|------|------|
| 업로드 주기 증가 | 활동 의지 감소 |
| 조회수 지속 하락 | 채널 영향력 약화 |
| 참여율(좋아요/조회수) 감소 | 팬덤 이탈 |
| 댓글 감성 부정 전환 | 커뮤니티 관계 악화 |
| 영상 길이 감소 | 콘텐츠 투자 감소 |

### ML / DL 역할

- **ML**: 정형 데이터 (업로드 주기·조회수·참여율) → 이탈 위험도 예측
  - Logistic Regression, RandomForest, XGBoost, LightGBM
- **DL**: 댓글 텍스트 BERT 감성 분석 → 숨겨진 번아웃 신호 탐지
  - KoBERT 활용 (한국어 댓글 처리)

### Target 정의
```
이탈 = 마지막 업로드 후 90일 이상 경과한 채널 = 1
활동 = 정상적으로 업로드 중인 채널 = 0
```

## 🎬 SCENE 5: 분석 결과
### "이런 채널이 위험하다"

> *"데이터가 말하는 이탈 전 공통 패턴입니다."*

### EDA 핵심 인사이트

- 업로드 간격이 **평균의 3배 이상** 늘어난 채널 → 이탈 위험 급증
- 최근 3개월 조회수가 **이전 3개월 대비 50% 이하** → 위험 신호
- 댓글 감성 점수가 **음수로 전환**된 채널 → 이탈 전조

### SHAP 해석 포인트

> *"단순히 '이탈 위험 있음'이 아니라 '왜 위험한지'를 설명합니다."*
> - 1순위: 업로드 주기 증가
> - 2순위: 댓글 감성 하락
> - 3순위: 참여율 감소

## 🎬 SCENE 6: 비즈니스 활용
### "광고주가 쓸 수 있는 방법"

> *"모델 결과를 실제 광고 계약에 이렇게 활용합니다."*

### 크리에이터 신용등급 시스템

| 등급 | 이탈 위험도 | 의미 | 광고주 액션 |
|------|-----------|------|------------|
| 🟢 A등급 | 낮음 (0~20%) | 안정적 활동 | 장기 계약 적합 |
| 🟡 B등급 | 중간 (20~50%) | 주의 필요 | 단기 계약 권장 |
| 🔴 C등급 | 높음 (50%~) | 위험 | 계약 재고 권장 |

### ROI 시뮬레이션

- 2025년 브랜드들의 인플루언서 캠페인 지출: **약 13조 6,200억 원**
  - 출처: [Shopify, 2025](https://www.shopify.com/kr/blog/influencer-marketing-statistics)
- 계약 중 이탈률 **5% 가정** → 손실 규모 약 **6,810억 원**
- 우리 모델로 C등급 사전 필터링 시 → **손실 방지 기대 금액 계산 가능**

## 🎬 SCENE 7: 한계 + 향후 과제

> *"모델의 한계를 솔직히 인정하고, 더 나아갈 방향을 제시합니다."*

### 한계

- YouTube API는 채널 소유자만 접근 가능한 **구독자 증감 추이·수익 데이터 미제공**
- **간접 지표** (업로드 주기·참여율)로 이탈을 추정하는 방식
- 건강·가족 등 **개인 사정으로 인한 비자발적 중단** 구분 불가

### 향후 과제

- 인플루언서 분석 도구 발전 + 자동화 마케팅 플랫폼 결합 시 더 정밀한 예측 가능
  - 출처: [한국인플루언서뉴스, 2026](https://www.koreainfluencernews.com/news/articleView.html?idxno=7823)
- 실제 광고 에이전시와 협력해 **계약 이력 데이터 확보** 시 모델 고도화 가능

## 🎬 SCENE 8: 결론
### "광고 계약 전, 이제는 데이터로 판단하세요"

> *"인플루언서 마케팅 시장 35조 원 시대. 계약 전 크리에이터의 활동 지속성을 데이터로 검증하는 시대가 시작됩니다."*

### 3줄 결론

1. 유튜버 이탈은 **예측 가능한 패턴**이 있다
2. **ML로 수치를, DL로 감성을** 분석해 이탈 위험도를 사전에 파악할 수 있다
3. 광고주는 이 모델로 **안전한 파트너를 선별**하고 마케팅 손실을 줄일 수 있다
