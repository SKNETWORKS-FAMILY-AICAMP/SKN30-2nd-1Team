### 1. 국내 인플루언서 마케팅 시장의 초고속 성장
2025년 기준 **국내 디지털 크리에이터 산업 매출은 약 5조 5천억 원** 규모에 달하며, 광고주들은 매년 미디어 광고비 내 크리에이터 장기 협업 예산 비중을 빠르게 확대하고 있습니다.

### 2. 단순 "인기 지표" 기반 의사결정의 심각한 한계
기존 광고주나 MCN 기업은 주로 구독자 수, 단순 누적 조회수, 채널 인지도 같은 정적 지표에만 의존하여 크리에이터를 선정합니다. 그러나 이는 **"현재의 인기"**일 뿐, **"미래의 안정성과 활동 지속 가능성"**을 대변해주지 못합니다. 
- 갑작스러운 업로드 중단(이탈)
- 조회수 및 시청자 참여도의 급격한 침체(정체/변동성)
- 커뮤니티 부정 반응(평판 악화)
위와 같은 리스크가 사전에 포착되지 않아 **수억 원대 장기 광고 계약금이 공중에 뜨는 비즈니스 사고**가 빈번하게 발생하고 있습니다.

### 3. 데이터 기반 선제적 리스크 방어 체계의 부재
기존 글로벌 분석 툴(플레이보드 등)은 실시간 순위와 현재 시점의 단순 통계 수치만 제공할 뿐, **한국어 댓글에 특화된 감성 흐름 분석**이나 **머신러닝 기반 활동 중단(Churn) 확률 예측**, 그리고 **SHAP 기반의 위험 요인 해석**을 통합 제공하는 플랫폼은 시장에 전무했습니다. 
"튜브어때"는 바로 이 비즈니스 공백(Market Gap)을 데이터와 인공지능으로 메우기 위해 탄생했습니다.

# 2. 핵심 비즈니스 프레임워크

### ✦ 이탈(Churn) 정의
- **Churn(이탈)**: YouTube 채널의 활동이 사실상 중단된 상태를 의미합니다. YouTube 크리에이터의 평균 업로드 주기를 감안하여, **Anchor 시점 기준 최근 180일간 신규 영상 업로드가 없는 채널**을 `is_churned = 1`로 명확하게 정의하였습니다. 
*(기획 초기의 90일 기준안은 시즌제/휴재 채널이 이탈로 과대 오분류될 위험이 있어, 180일을 정밀 기준선으로 확정하였습니다.)*

### ✦ Operational Targeting (실무적 타겟팅 전략)
- **마케팅 예산 및 자원 한계**: 광고주 및 MCN 마케터는 모든 크리에이터를 전수 검증하거나 예방 조치를 취할 수 없습니다. 따라서 튜브어때 AI 모델은 예측 위험도가 가장 높은 **상위 K% 고위험 크리에이터 군을 정밀 타겟팅**하는 시나리오를 기본 모델링 프레임워크로 삼습니다.

### ✦ Main KPI (Primary)
- **Lift@K (랜덤 대비 선별 효율)**: 마케팅 타겟팅의 비즈니스 효율성을 직접적으로 입증합니다.
  $$\text{Lift@K} = \frac{\text{Precision@K}}{\text{Prevalence (전체 이탈율)}}$$

### ✦ Secondary KPI
- **Recall@K (재현율)**: 이탈 크리에이터 중 예측 고위험군이 커버한 비율 (조기 방어 커버리지)
- **Precision@K (정밀도)**: 타겟 대상 채널 중 실제 이탈 채널의 비율 (예산 낭비 최소화)

### ✦ Diagnostic KPI
- **PR-AUC (Precision-Recall AUC)**: 심각한 클래스 불균형 환경에서 모델 랭킹의 전반적 신뢰도를 판단하는 핵심 보조 평가 지표로 사용합니다.

# 3. 프로젝트 목표
1. **비즈니스 리스크를 사전 예측하는 이진 분류 체계 구축**  
   현재 인기 랭킹에서 나아가, 6가지 통합 리스크 차원(이탈 확률, 정체 확률, 조회수 변동성, 업로드 규칙성, 민감 키워드 점수, 활성 시청자 군집 점수)을 머신러닝/딥러닝으로 학습하여 크리에이터의 미래 '생존 등급'을 예측합니다.
2. **비즈니스 요구에 극대화된 리밸런싱 모델링**  
   이탈 채널을 사전에 잡아내는 것(Recall)이 오탐(False Positive)보다 훨씬 크리티컬한 비즈니스 기회비용을 가집니다. 이에 따라 리밸런싱 및 임계값 튜닝(Threshold Tuning)을 통해 **Recall 80% 이상**의 최적의 예측 성능을 확보합니다.
3. **SHAP 기반의 '설명 가능한 AI (XAI)' 제공**  
   광고주가 이탈 위험을 납득할 수 있도록, 개별 크리에이터 채널의 위험 유발 요인 Top-3(구독자 하락, 업로드 불규칙성, 최근 미업로드 횟수 등)를 투명하게 계량화하여 대시보드에 시각화합니다.

### 🛡️ 데이터 누수 방지(Data Leakage Prevention) 철칙
1. **타깃 변수 격리**: 이탈 라벨 `is_churned`를 만드는 데 직접적인 역산이 들어가는 **`days_since_last_upload` 피처는 모델 학습 피처에서 완벽히 제외**하였습니다.
2. **수렴 이상값(Clip) 보정**: 분모가 0이 되어 비정상적으로 폭증하는 비율 피처에 대해 강제 클리핑 기법을 적용하였습니다:
   - `upload_freq_change_rate`: `clip(-5, 5)`
   - `avg_engagement_rate` (조회수가 극소인 영상에서 비정상적으로 팽창): `clip(0, 1)`
3. **전처리 엄격 격리**: 모든 정규화 스케일러 및 결측 대체 피팅은 **오직 Train 세트에서만 `fit`**을 진행하고, Validation 및 Test 세트에는 오로지 `transform`만 투영하였습니다.

# 6. AI/ML 모델링 및 리밸런싱 비교

### 💡 2가지 파이프라인 검증 시나리오 설계

```
[Pipeline A] Imbalanced Base
┌───────────────────────────────────────────────────────────────────────────────┐
│ Train Set (80%) ──▶ Stratified 3-Fold CV ──▶ Tuning via ROC-AUC ──▶ Threshold = 0.50 │
└───────────────────────────────────────────────────────────────────────────────┘

[Pipeline B] Rebalanced & Threshold-Tuned (우리의 최종 제안)
┌───────────────────────────────────────────────────────────────────────────────┐
│ Train (60%) ──▶ 5-Fold CV via F2-Score ──▶ Valid-based Threshold Search ────┐  │
│                                           (Target Recall >= 0.80)            │  │
│                                                      ▼                       │  │
│ Test Set (20%) ◄───────────────────────── Final Ensemble (Threshold = 0.385) │  │
└───────────────────────────────────────────────────────────────────────────────┘
```

1. **기본 불균형 파이프라인 (Pipeline A)**: 
   - 8:2 분할 후 교차 검증 및 튜닝 지표로 **ROC-AUC**를 사용하여 학습. 의사결정 임계값을 디폴트 값인 **`0.50`**으로 고정 설정.
2. **리밸런싱 & 임계값 튜닝 파이프라인 (Pipeline B)**:
   - 데이터 누수를 원천 방어하기 위해 데이터를 **Train(60%), Validation(20%), Test(20%)**로 완전히 3중 격리 분할.
   - 불균형을 극복하기 위해 비용 민감 학습(`scale_pos_weight`, `class_weight='balanced'`)을 적용하고, **F2-Score** 지표를 최적화 목표로 K-Fold(CV=5) 교차 검증 튜닝.
   - Validation 셋을 사용하여 이탈 크리에이터 재현율(Recall) 80% 이상을 안정적으로 수립하기 위해 0.005 단위 임계값 그리드 서치 전개 -> **최종 비즈니스 의사결정 임계값 `0.385` 확정**.

# 7. 설명 가능한 AI (SHAP XAI 해석)

최종 앙상블 모델의 의사결정 판단 기준을 입증하고 현업 마케터에게 인과관계를 설명하기 위해 SHAP 글로벌 영향도 분석을 실행했습니다.

```
                  SHAP Global Feature Importance (RandomForest)
                  
  subscriber_count         ██████████████████████████ (가장 높은 이탈 영향력)
  regularity_score         ████████████████████ (채널 안정 유지 수비 지표)
  collected_video_count    ████████████████
  hiatus_count_30d         ████████████ (30일 초과 미업로드 발생 - 적색 경보)
  total_views              █████████
  avg_view_count           ██████
  sensitive_score          ████
```

### 💡 주요 인과관계 도출 및 해석
1. **구독자 수 (`subscriber_count`)**: 채널의 팬덤 기초 체력 지표. 구독자 수가 임계점 이하로 적은 군소 채널일수록 이탈 확률 상승 기여도가 수직 상승합니다.
2. **규칙성 점수 (`regularity_score`)**: 업로드가 일관적이고 주기적인 채널은 SHAP 기여가 강한 음수(-) 방향으로 작용하여, 활동 중단 위험을 낮추는 가장 안전한 방어막 역할을 하고 있음을 입증합니다.
3. **최근 장기 미업로드 횟수 (`hiatus_count_30d`)**: 최근 30일 이내에 30일이 넘는 긴 미업로드 공백이 빈발할수록 Churn 확률 점수에 막대한 가산점이 부여되며, 이탈로 치닫는 직전 단계의 확실한 "최종 경보음" 역할을 수행합니다.

# 9. 비즈니스 마케팅 전략 & 시나리오

AI 예측 점수를 현업의 실무 예산 운용에 즉시 결합하기 위해 다이내믹 의사결정 시나리오를 제안합니다.

### 1. Risk-Based Differential Incentives (위험 등급별 차별화 리텐션)
- **🔴 고위험군 (이탈 등급 D/F | 이탈 점수 80% 초과)**: 
  - 플랫폼 핵심 크리에이터일 경우 즉각 Win-back 프로그램 적용.
  - 전담 매니저 매칭, MCN 수수료 일시 감면, 창작 장비 긴급 지원 등 강력한 혜택 투여.
- **🟡 경고군 (이탈 등급 B/C | 이탈 점수 40% ~ 80%)**: 
  - 업로드 규칙성 복구를 유도하는 넛지(Nudge) 캠페인 작동.
  - KoBERT 댓글 모니터링을 통한 팬덤 부정 키워드 사전 피드백 전송.
- **🟢 우수군 (이탈 등급 A | 이탈 점수 40% 이하)**:
  - 광고주 장기 1년 스폰서십 계약 추천 우선 배치.
  - 크리에이터 보너스 인센티브 제공.

<br>

### 2. Economic Threshold Control (비즈니스 예산별 트레이드오프 동적 제어)
> [!IMPORTANT]
> 고정된 단 하나의 임계값을 사용해 의사결정을 하는 것은 예산 누수를 초래합니다. 마케터는 광고 계약 규모에 따라 최적 임계값을 유연하게 대조해야 합니다.

- **메가 크리에이터 (구독자 상위 5%) 타겟 시**: 
  - 해당 채널 이탈 시 플랫폼 광고 매출 타격이 지대하므로, **Pipeline B (Recall 86.33% 최적 임계값 0.385)**를 투입하여 이탈 조짐을 털끝만큼이라도 보일 경우 선제적 방어 비용을 전폭적으로 투입합니다.
- **마이크로 크리에이터 (구독자 하위 70%) 타겟 시**: 
  - 예산 투입 대비 ROI 보존을 위해, 임계값을 0.50 이상으로 조여 **Precision(정밀도)을 50% 이상으로 방어**하여 불필요하게 낭비되는 리텐션 쿠폰/컨설팅 예산 누수(FP 비용)를 경제적으로 차단합니다.

# 10. 기술적 트러블슈팅 (Troubleshooting)

### 1. 클래스 불균형에 의한 정상 클래스 편향 개선
- **문제점**: 이탈률이 20.8% 수준인 불균형 환경에서 기본 머신러닝 모델(Pipeline A)을 학습시켰을 때, 모델이 다수 클래스인 '정상' 채널로 지나치게 편향되어 실제 이탈하는 크리에이터를 거의 잡아내지 못하는 문제(Recall 32.00%)를 겪었습니다.
- **해결책**:
  1. 모델 최적화 탐색 가중 지표를 Accuracy/ROC-AUC에서 소수 클래스 검출에 패널티를 주는 **F2-Score**로 피벗하였습니다.
  2. XGBoost의 `scale_pos_weight` 튜닝과 로지스틱 회귀의 `class_weight='balanced'` 가중 가중치 설정을 결합하였습니다.
  3. 20% 분리된 Validation 세트의 예측 확률 기반으로 비즈니스 목표값(Recall >= 80%)을 통과하는 최적 임계값인 **0.385**를 서치하여 도출해 냈습니다.
- **최종 성과**: 최종 격리 Test 세트 평가 결과, 전체 랭킹 변별력(ROC-AUC 0.795)은 고스란히 보존하면서 **이탈 채널 재현율(Recall)을 32.00%에서 86.33%로 54.33%p 비약적으로 증가**시키는 데 성공하였습니다.

<br>

### 2. 피처 스케일링 누락에 따른 로지스틱 회귀 미수렴 극복
- **문제점**: 초기 Pipeline A 파이프라인에서 피처 간 상이한 범위 격차로 인해 로지스틱 회귀 알고리즘의 Solver가 가중치 수렴에 실패하여 ROC-AUC가 0.6740 수준에 머물렀고, 앙상블 예측 시 모델 성능을 저해하는 노이즈로 작용하였습니다.
- **해결책**:
  1. 로지스틱 회귀의 다중공선성을 억제하기 위해 L1 페널티 규제(`liblinear` solver 연계) 튜닝 공간을 명시적으로 투입하였습니다.
  2. 트리 계열 부스팅 모델(XGBoost, LightGBM)과 Soft Voting으로 가중 확률 결합을 재조정하여 스케일 격차에 따른 불안정성을 최종 앙상블 계층에서 극복하였습니다.
- **최종 성과**: 최종 Validation 셋 평가에서 로지스틱 단독 성능을 **ROC-AUC 0.8448**까지 상승시켰으며, 최종 3대 모델 앙상블 구조로 수렴 안정성 및 판별 신뢰도 향상을 이루어 냈습니다.
