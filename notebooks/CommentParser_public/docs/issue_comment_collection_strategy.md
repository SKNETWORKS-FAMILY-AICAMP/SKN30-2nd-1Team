# Issue: YouTube 댓글 수집 전략

## 배경

배치 테스트 중 일부 영상의 댓글 수가 예상보다 훨씬 많은 것을 확인.

| 채널 | 영상 | 댓글 수 |
|------|------|---------|
| 어썸하은 (8004) | TN0jmoY5rcM | 22,285 |
| 어썸하은 (8004) | jqLPqamsDyw | 30,554 |

yt-dlp는 댓글을 페이지 단위로 순차 요청하므로, 댓글 수가 많을수록 수집 시간이 선형으로 증가함.

---

## yt-dlp 정렬 옵션 현황

| 정렬 방식 | yt-dlp 지원 여부 | 옵션 |
|------|------|------|
| 인기순 (YouTube Top Comments) | ✅ | `--extractor-args "youtube:comment_sort=top"` |
| 최신순 | ✅ | `--extractor-args "youtube:comment_sort=new"` |
| 업로드 시점 기준 (오래된 순) | ❌ | 미지원 — 전체 수집 후 DB 정렬 필요 |
| 순수 좋아요 순 | ❌ | 미지원 — 전체 수집 후 DB 정렬 필요 |

---

## 분석 목적별 요구사항

| 분석 목적 | 필요한 댓글 | 전체 수집 필요? |
|------|------|------|
| 인기 댓글 분석 | 인기순 상위 N개 | ❌ (`comment_sort=top` + `--max-comments N`) |
| 최근 반응 분석 | 최신 N개 | ❌ (`comment_sort=new` + `--max-comments N`) |
| 초기 반응 분석 (업로드 직후) | 오래된 순 N개 | ✅ 전체 수집 후 정렬 |
| 좋아요 순 분석 | 전체 정렬 필요 | ✅ 전체 수집 후 정렬 |
| 업로더-시청자 상호작용 분석 | 업로더 댓글 + 대댓글 | 상황에 따라 다름 |

---

## 선택지

### Option A. 전체 수집
- **장점**: 모든 분석 가능, DB에서 자유롭게 정렬/필터링
- **단점**: 댓글 수만큼 수집 시간 증가, 저장 용량 부담
- **적합한 경우**: 정밀 분석, 소수 영상 대상

### Option B. 수집량 제한 (`--max-comments N`)
- **장점**: 수집 시간 예측 가능, 용량 절감
- **단점**: 특정 정렬 방식에서만 의미 있음 (인기순/최신순), 업로드 초기 댓글 분석 불가
- **적합한 경우**: 대량 배치, 인기/최신 댓글 위주 분석

### Option C. 댓글 수 임계값으로 스킵
- **장점**: 배치 시간 예측 가능
- **단점**: 인기 영상(댓글 많음) 데이터 누락
- **적합한 경우**: 빠른 파일럿 수집

### Option D. 정렬 방식별 분리 수집
- 인기순/최신순 → `--max-comments N`으로 빠르게 수집
- 초기 반응/좋아요 순 → 별도로 전체 수집 대상 영상 선별
- **적합한 경우**: 분석 목적이 명확히 구분될 때
